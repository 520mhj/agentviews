# 浏览器工具对比协议

目标是检验 AVS 的语义交互层是否为调用方 Agent 减少探索、上下文和接入成本，不预设它在任何任务都优于其他工具。

## 公平基线

- 对比 Playwright 的角色/名字定位、可访问性快照、自动等待、读取及断言，不将其等同于截图猜坐标。
- 允许双方正常使用工具能力；同样限制来源、用户授权、敏感操作与验收条件。
- AVS 不加入预写站点 adapter；另一侧也不借助本轮已知答案或预写任务路径。

## 可检验假设

| 假设 | 指标 |
| --- | --- |
| 紧凑语义视图减少探索 | 首次有效动作前的调用、发现耗时、模型用量 |
| 新鲜断言与恢复降低错误 | 名字变化、重名、DOM 替换、动态更新的恢复率和额外调用 |
| 按目标读取与结构化采集降低上下文 | 相同验收结果的正确率、返回体积、临时脚本长度 |
| 日常浏览器接入降低准备成本 | 初始化/人工步骤、登录代理准备时间、焦点和标签页保护 |
| 独立只读监听支持恢复 | 回合断开后的事件记录、游标恢复、丢失提示、原目标保持和停止资源释放 |

功能存在不自动等于性能优势。安全漏拦截独立记录，不能被速度或完成率抵消。

## 任务与环境

根据实际用户需要选择中性阅读、站内搜索、动态列表、结构化读取和恢复任务，明确页面起点、允许来源、完整输出及验收断言。业务判断属于实验中的 Agent，不写入工具的固定任务流程。

- 两侧使用同一任务和验收，不分配不同内容、日期范围或字段。
- 匹配浏览器、机器负载、网络、登录/代理状态、缓存、模型、推理档位、任务提示和预算。无法匹配的差异逐项披露。
- 核心执行与安装/准备成本分别测量，不将已登录环境与未登录环境混为性能结论。
- 每次从相同起点进入独立 Agent 会话；任务局部答案和控件路径不跨组共享。先做不计正式结果的连接与日志预检。
- 多轮配对并交替/随机执行顺序，预先固定重复次数和预算，不删除失败或不利样本。
- 登录阻塞由用户处理。重要操作对双方使用相同的明确授权条件，区分用户亲自完成和授权 Agent 执行，并记录等待时间。未经允许换站、换任务或自动确认记为 scope_violation，不算成功。
- 异步、取消、断连和编辑器能力先用本地无副作用夹具，不以真实账户的不可逆业务验证。

## 记录与判定

每次保存任务 ID、配对 ID、工具/源文件摘要、环境、执行顺序、预算和验收结果，记录输入及经过隐私过滤的原始证据。密码、验证码、cookie、配对 token 和含凭据 URL 不进入报告。

分别记录 setup、主动墙钟、总墙钟、人工等待、浏览器调用和清理时间。并行区间不能重复求和。

分别记录模型实际 input、cached input、output、reasoning 和 total；按供应商字段定义避免重复累计。工具文本体积使用同一 tokenizer，仅作上下文体积对比，不能冒充模型账单。实际 usage 不可获得时写 N/A，不推算精确 token 或费用。

结果区分 completed、blocked_login、blocked_user_action、failed、timeout、skipped 和 scope_violation。CLI 退出成功、事件派发和未验证的页面变化不是 completed。

公布所有正式尝试的完成率，以及成功样本主动时间的配对差值、模型用量、恢复轮次、误拦截、漏拦截、意外开关页和焦点变化。双方不同时成功的配对不能用于成功任务加速比，但仍保留在完成率与资源消耗中。

## 发布

先披露失败、观察缺口和环境差异，再讨论有证据的优势。给出样本规模、重复次数、适用场景、代价和原始证据。小样本不能外推尾延迟、长期稳定性或全站通用能力；没有优势时如实写“该场景直接使用其他工具已足够”。
