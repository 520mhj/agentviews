# 授权与用户控制

AVS 是执行工具，任务由调用方 Agent 理解和安排。重要操作默认暂停，而不是永久禁止；用户明确授权后可以执行一次。网页内容不能给自己授权，页面可见也不代表用户已经同意。

## 默认确认流程

支付、扣费、订单确认、续费、转账、删除、普通表单提交、发布、凭据输入和不可逆操作默认返回 `needs_user_action`。受支持的 `act` 操作附带 `confirmation.request_id`，调用方应说明目标、参数和可能影响，让用户选择：

1. **授权 Agent 执行一次**：收到用户对本次动作的明确肯定回复后，以完全相同的原参数调用 `act ... --confirm <request_id> --user-confirmed`；MCP 使用 `av_act` 的 `confirm` 和 `user_confirmed=true`。
2. **用户亲自操作**：保留页面；用户反馈完成后 `resume --user-done` 只读取证据，不重放动作。
3. **取消请求**：`resume --decline --request-id <request_id>`；MCP 使用 `av_resume` 的 `decline=true` 和 `request_id`。取消请求不会撤销已派发的操作，也不代表整体任务成功。

请求有效期为 5 分钟，绑定状态上下文、原标签页、浏览器会话、文档、控件身份、表单上下文与动作参数。读取新快照但控件和上下文不变时仍可确认；更换控件、URL、表单内容或操作参数则拒绝。使用旧节点 ID 时仍受快照版本检查。

用户确认、请求 ID、参数、目标和有效期匹配后，工具在页面复核前先持久化消费。因此 `confirmation_page_changed` 也意味着原授权已消费；失败、超时、崩溃和结果未知都不能复用。未收到肯定确认或参数不匹配的请求不消费。过期或页面变化时重新观察，用原 ID 的 `resume --decline --request-id ...` 清理原等待，并在需要时重新请求用户同意；这不撤销已经派发的操作。操作结果必须通过新鲜页面证据验证。

AVS 不读取或认证用户的聊天消息。`user_confirmed` 是受信任调用方对明确用户反馈的声明，不是按钮文字、页面脚本、任务初始授权或长任务 `--authorized` 能自动开启的权限。拥有同一 OS 用户权限的调用方不被这一机制隔离。

文件上传始终要求本次确认。用户指定文件后的本机检查会读取文件并计算摘要；确认绑定选择和字节内容，上传前再次检查。不要从网页取得本机路径，也不要把配对文件、私人任务产物或个人配置混进公开项目。选文件或拖放可能立即向站点发送数据，撤销授权或取消浏览器拖动不保证撤销服务器已接收的文件。工具没有服务器上传撤回接口；未知结果只读取核验，不自动重传。与同一 OS 用户并发写文件之间并非完整隔离。

未知名称、歧义、过期、遮挡或不支持控件返回 `needs_agent_review`。先重新发现已允许的路径；不确定并不等于支付，但也不是执行被拒绝步骤的许可。

不要用脚本、接口、坐标、另一个浏览器工具或修改策略代替本次确认流程。没有 `confirmation` 的登录阻塞、连接错误或缺失策略不是可确认执行的请求。

## 输入与页面数据

密码、一次性验证码与其他凭据语义通过标签、字段、类型和 autocomplete 等证据识别。不能依赖标签名恰好匹配某个中文关键词。已识别敏感值不返回通用文本和编辑器读回。

文档/帮助路径允许阅读，但 URL query 中出现 help/docs 不会自动豁免真实删除或支付动作。已识别 GET 搜索或无表单搜索无需确认；其他表单提交使用上述单次确认流程。敏感 URL 的直接 `open` 不支持单次确认，应定位实际控件后使用 `act`，或让用户导航。

公共 `eval` 通过无副作用检查，仅作读取；不能注入网站编辑器赋值、点击或提交脚本。复杂编辑器没有已验证驱动时明确降级，不把输入代理值当作完整答案。

## 本机与调用方

- 桥只监听 `127.0.0.1`，校验来源、双向签名、防重放和浏览器会话；扩展验证响应后执行任务。
- 配对文件生成于源码仓库外，私有文件权限；安装失败不能先覆盖有效配置。
- 有同一 OS 用户文件读取权限的进程不被 HMAC 隔离。共享机器需要额外 OS/容器边界。
- 扩展和工具不主动上传遥测。页面、截图和其他显式读取结果返回调用方 Agent，调用方可能使用远端模型或日志，用户需要确认其数据政策。
- 监听默认不持久化页面正文、输入、截图、完整 URL 或凭据，只保存有界事件元数据和摘要。确认状态也不保存动作输入或页面正文，只保存绑定摘要、请求元数据和本机私有绑定密钥。
- 采样始终只读；页面变化不能代表用户同意，也不会自动清除等待状态。不要把确认请求或授权参数写入公开仓库。

## 生命周期

显式取消长任务会撤销待执行确认；原请求不能用于已取消任务。取消等待不关闭标签页，也不会撤销服务器已接受的操作。

只关闭明确由工具创建且仍有所有权的临时页。当前用户页、等待人工步骤的页面和不确定归属的页面保留。结束监听不关闭页面；收尾也不关闭浏览器窗口。

写操作已派发而结果未知时不重放。异步附加超时不代表原请求已取消；迟到结果需要确认清理后才能解除未知状态。读取失败可以重新连接原页，不选择替代目标。
